# Project notes and scope

- Source context: user-provided archive of COMP90016 Computational Genomics workshops, assignment notebooks and data (2024).
- Public version: **fresh AI-assisted educational adaptation**, not copied workshop code or assignment answers.
- Modules selected for self-contained demonstrations: DNA sequence operations, FASTQ summaries, simple VCF inspection, Kraken2-style report summary, and per-cell count QC.
- Original archive deliberately excluded: faculty workshop and solution notebooks, assessed assignments, exam, login tables, instructor slides, large FASTQ/BAM/VCF files and other data with unclear redistribution rights.
- No claims that full genomics workflows such as Snippy, Flye, BLAST, IQ-TREE2, Kraken2 or scRNA-seq analysis were rerun on this demonstration dataset.
- Test results are local standard-library unit tests and do not constitute wet-lab, clinical or pipeline validation.
