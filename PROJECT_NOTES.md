# Project provenance

- Independent, post-course, AI-assisted portfolio adaptations of common computational-genomics methods.
- Original learning materials and assessed notebooks were not copied into this repository.
- Synthetic data only; no identifying records, third-party classroom materials, copyrighted solution sheets, or private sequencing samples.
- Initial examples: DNA sequence utilities, FASTQ metrics, VCF classification, report parsing, per-cell QC.
- Later additions: global pairwise alignment, exact matching, short k-mer graph paths, p-distance matrices, simple forward ORFs, more unit tests, and non-executable analysis workflow notes.
- This repository documents **new demonstrations**, not an assertion that each implementation was authored during coursework.
- Workflows requiring external software are discussed, not executed or validated. All code is educational rather than clinical.
