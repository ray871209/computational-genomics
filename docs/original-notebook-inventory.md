## Recommended review for each original notebook

1. Mark cells as personally written code, adapted course starter code, instructor text, or unknown.
2. Remove student IDs, tokens, local paths, credentials, grading instructions, answer keys, and institution-provided material that is not licensed for redistribution.
3. Document the provenance and reuse terms of inputs and third-party code.
4. For executed results, preserve commands, parameter choices, software versions (when actually recorded), and original numerical results; do not backfill absent values.
5. Independently reproduce shareable analyses on authorized or synthetic inputs; compare with prior outputs and disclose differences.
6. Only after this review, publish selected extracts in separate `workshop-records/` examples, not entire original notebooks.
