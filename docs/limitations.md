# Scope and reproducibility

This is an independent, AI-assisted educational software portfolio, **not an archival upload of graded submissions**, third-party laboratory data, or teaching handouts.

**Implemented and unit-testable in pure Python:** sequence utilities, FASTQ QC, VCF parsing, metagenomics report summaries, simple single-cell QC, exact-match search, global pairwise alignment, a toy de Bruijn graph assembler, aligned-sequence p-distances and a basic forward ORF finder.

**Not implemented as executable pipelines:** FastQC, Snippy, BWA, minimap2, Flye, QUAST, Prokka, BLAST, IQ-TREE, Kraken2, Seurat or variant interpretation. Study notes mention these tools only to explain broader workflows.

All examples use synthetic data. Results are not clinically valid. Do not interpret the code as validated research pipelines.
